# Retail Sales Performance Dashboard — Power BI

## Overview
An interactive Power BI dashboard built using the Sample Superstore dataset to explore retail sales and profitability.

## Dashboard Features
- **KPI Cards:** Total Sales, Total Profit, and Total Orders
- **Sales Trend Analysis:** Sales performance by year
- **Regional Analysis:** Sales across West, East, Central, and South
- **Category Analysis:** Profit by Technology, Office Supplies, and Furniture
- **Interactive Date Slicer:** Filter results by a selected date range

## Tools & Technologies
- Microsoft Power BI Desktop
- Data Visualization
- Sample Superstore Dataset

## Project Files
- `Retail_Sales_Performance_Dashboard.pbix` — Power BI report
- `screenshots/` — Dashboard preview images
